# SoftNest Fabric Care

Next.js redesign of the SoftNest Fabric Care website.

## Current scope

The site preserves the redesigned Next.js structure and hero, followed by the
complete content flow from the original SoftNest website:

- Before-and-after results
- Cleaning services and trust points
- Four-step cleaning process
- Health and family benefits
- Customer reviews and FAQ
- Company story, service-area map, quote form, and footer

## Development

```bash
npm install
npm run dev
```

The original static site files were preserved locally under `.legacy-backup/`
before the project was converted to Next.js.
